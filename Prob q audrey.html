📐 Probability Practice

Two-Step Problems  ·  Two Cases  ·  Step 2 changes depending on Step 1

🧮 Total Probability Formula

P(Event) = P(Case 1) × P(Event | Case 1)
           + P(Case 2) × P(Event | Case 2)

Step 1 → creates two possible situations
Step 2 → probability shifts based on which situation occurred
1
Ball Transfer

Bag A contains 3 red and 2 blue balls. One ball is randomly drawn from Bag A and placed into Bag B, which originally contains 2 red and 4 blue balls. A ball is then randomly drawn from Bag B.
Find the probability that the ball drawn from Bag B is:

(a) red (b) blue
Solution
Case — Step 1 (draw from A) P(Case) Bag B becomes P(red|Case) P(blue|Case)
Red ball drawn from A 3/5 3R + 4B = 7 3/7 4/7
Blue ball drawn from A 2/5 2R + 5B = 7 2/7 5/7
(a) P(red from Bag B)
= (3/5)×(3/7) + (2/5)×(2/7) = 9/35 + 4/35 = 13/35
(b) P(blue from Bag B)
= (3/5)×(4/7) + (2/5)×(5/7) = 12/35 + 10/35 = 22/35
2
Two Urns

Urn X contains 5 white and 3 black balls. Urn Y contains 2 white and 6 black balls. A fair coin is flipped: if Heads, draw from Urn X; if Tails, draw from Urn Y.
Find the probability that the drawn ball is:

(a) white (b) black
Solution
Case — Step 1 (coin flip) P(Case) Draw from P(white|Case) P(black|Case)
Heads 1/2 Urn X (5W+3B) 5/8 3/8
Tails 1/2 Urn Y (2W+6B) 2/8 = 1/4 6/8 = 3/4
(a) P(white)
= (1/2)×(5/8) + (1/2)×(2/8) = 5/16 + 2/16 = 7/16
(b) P(black)
= (1/2)×(3/8) + (1/2)×(6/8) = 3/16 + 6/16 = 9/16
3
Die + Card Draw

A fair die is rolled. If the result is 1 or 2, a card is drawn from Set A = {1, 2, 3, 4, 5}. If the result is 3, 4, 5, or 6, a card is drawn from Set B = {1, 2, 3}.
Find the probability that the card shows:

(a) an odd number (b) an even number
Solution
Case — Step 1 (die roll) P(Case) Card set P(odd|Case) P(even|Case)
Die shows 1 or 2 2/6 = 1/3 Set A {1,2,3,4,5} 3/5 2/5
Die shows 3–6 4/6 = 2/3 Set B {1,2,3} 2/3 1/3
(a) P(odd)
= (1/3)×(3/5) + (2/3)×(2/3) = 9/45 + 20/45 = 29/45
(b) P(even)
= (1/3)×(2/5) + (2/3)×(1/3) = 6/45 + 10/45 = 16/45
4
Weather

The probability that it rains on a given day is 2/5. If it rains, the probability a student brings an umbrella is 4/5. If it does not rain, the probability is only 1/5.
Find the probability that the student:

(a) brings an umbrella (b) does not bring an umbrella
Solution
Case — Step 1 (weather) P(Case) P(umbrella|Case) P(no umbrella|Case)
It rains 2/5 4/5 1/5
No rain 3/5 1/5 4/5
(a) P(brings umbrella)
= (2/5)×(4/5) + (3/5)×(1/5) = 8/25 + 3/25 = 11/25
(b) P(no umbrella)
= (2/5)×(1/5) + (3/5)×(4/5) = 2/25 + 12/25 = 14/25
5
Factory QC

A factory has two machines. Machine P produces 40% of daily output with a 5% defect rate. Machine Q produces 60% with a 10% defect rate. An item is randomly selected from the day's output.
Find the probability that the item is:

(a) defective (b) not defective
Solution
Case — Step 1 (which machine) P(Case) P(defective|Case) P(good|Case)
From Machine P 0.40 0.05 0.95
From Machine Q 0.60 0.10 0.90
(a) P(defective)
= (0.40)(0.05) + (0.60)(0.10) = 0.020 + 0.060 = 0.08
(b) P(not defective)
= (0.40)(0.95) + (0.60)(0.90) = 0.380 + 0.540 = 0.92

Without Replacement

A box contains 4 red and 6 blue chips. Two chips are drawn one at a time without replacement.
Find the probability that the second chip is:

(a) red (b) blue
Solution
Case — Step 1 (1st draw) P(Case) Remaining (9 chips) P(2nd red|Case) P(2nd blue|Case)
1st chip is red 4/10 = 2/5 3R + 6B 3/9 = 1/3 6/9 = 2/3
1st chip is blue 6/10 = 3/5 4R + 5B 4/9 5/9
(a) P(2nd chip is red)
= (2/5)×(1/3) + (3/5)×(4/9) = 6/45 + 12/45 = 18/45 = 2/5
(b) P(2nd chip is blue)
= (2/5)×(2/3) + (3/5)×(5/9) = 12/45 + 15/45 = 27/45 = 3/5
7
Basketball

Player A takes a free throw and scores with probability 3/4. If A scores, Player B shoots next from Zone 1 (scoring probability = 2/3). If A misses, Player B must shoot from Zone 2 (scoring probability = 1/2).
Find the probability that Player B:

(a) scores (b) misses
Solution
Case — Step 1 (Player A) P(Case) B shoots from P(B scores|Case) P(B misses|Case)
A scores 3/4 Zone 1 2/3 1/3
A misses 1/4 Zone 2 1/2 1/2
(a) P(Player B scores)
= (3/4)×(2/3) + (1/4)×(1/2) = 1/2 + 1/8 = 4/8 + 1/8 = 5/8
(b) P(Player B misses)
= (3/4)×(1/3) + (1/4)×(1/2) = 1/4 + 1/8 = 2/8 + 1/8 = 3/8
8
Traffic Lights

The probability of hitting a red light at Junction A is 3/5. If A is red, the probability of also hitting red at Junction B is 4/5. If A is green, that probability drops to 2/5.
Find the probability that Junction B shows:

(a) red (b) green
Solution
Case — Step 1 (Junction A) P(Case) P(B red|Case) P(B green|Case)
A is red 3/5 4/5 1/5
A is green 2/5 2/5 3/5
(a) P(B is red)
= (3/5)×(4/5) + (2/5)×(2/5) = 12/25 + 4/25 = 16/25
(b) P(B is green)
= (3/5)×(1/5) + (2/5)×(3/5) = 3/25 + 6/25 = 9/25
9
Medical Screening

In a population, 20% of people have a certain condition. A screening test returns positive for 90% of those who have the condition, and for 30% of those who do not.
A person is randomly selected and tested. Find the probability the result is:

(a) positive (b) negative
Solution
Case — Step 1 (health status) P(Case) P(positive|Case) P(negative|Case)
Has condition 0.20 0.90 0.10
No condition 0.80 0.30 0.70
(a) P(test positive)
= (0.20)(0.90) + (0.80)(0.30) = 0.18 + 0.24 = 0.42
(b) P(test negative)
= (0.20)(0.10) + (0.80)(0.70) = 0.02 + 0.56 = 0.58
10
Exam Preparation

A student studies with probability 2/3 and skips studying with probability 1/3. If the student studies, the probability of passing is 9/10. If the student skips, the probability of passing is only 1/5.
Find the probability that the student:

(a) passes the exam (b) fails the exam
Solution
Case — Step 1 (preparation) P(Case) P(pass|Case) P(fail|Case)
Studies 2/3 9/10 1/10
Does not study 1/3 2/10 = 1/5 8/10 = 4/5
(a) P(passes)
= (2/3)×(9/10) + (1/3)×(2/10) = 18/30 + 2/30 = 20/30 = 2/3
(b) P(fails)
= (2/3)×(1/10) + (1/3)×(8/10) = 2/30 + 8/30 = 10/30 = 1/3
